# Imagens recomendadas

O projeto ainda nao possui fotografias proprias. Para evitar imagens genericas ou sem autorizacao, nenhuma imagem externa foi inserida automaticamente.

## `oficina-equipe.webp`

- Uso: bloco de apresentacao do produto ou contato na landing page.
- Conteudo: equipe real trabalhando em uma oficina cliente, sem pose e sem marcas de terceiros em destaque.
- Dimensao recomendada: 1600 x 1067 px (proporcao 3:2).
- Exportacao: WebP, qualidade entre 75 e 82, ate 250 KB.
- Texto alternativo sugerido: `Equipe acompanhando os servicos da oficina pelo Giro`.

## `giro-patio.webp`

- Uso: hero da landing page, substituindo o mockup em HTML quando houver uma captura final do produto.
- Conteudo: captura real da tela do patio com dados anonimizados e textos legiveis.
- Dimensao recomendada: 1600 x 1000 px (proporcao 8:5).
- Exportacao: WebP, qualidade entre 80 e 86, ate 300 KB.
- Gerar tambem: `giro-patio-800.webp`, com 800 x 500 px para telas menores.

## `giro-og.webp`

- Uso: imagem de compartilhamento (`og:image`) quando o dominio publico estiver definido.
- Conteudo: marca, uma frase curta e uma captura real do produto.
- Dimensao recomendada: 1200 x 630 px.
- Exportacao: WebP ou JPG, ate 300 KB.

Nao usar fotos de banco de imagens com carros esportivos, oficinas estrangeiras ou cenas excessivamente produzidas. As imagens devem comprovar o contexto real do produto, nao apenas decorar a pagina.
